# Lx8 Labs

Small, fast, honest software.

## Flagship

**Tupã** — the honest, local-first AI assistant that runs on your laptop:
memory you can see, governance you can audit, zero per-token bills.
macOS · iOS · Android · web.

## Products

- **aimem** — hybrid (vector + FTS5) markdown memory index & MCP server; one Rust binary, works with any MCP-compatible AI.
- **Curupira** — personal digital security guardian. Watches over your devices; never touches.
- **mattermem** — local-only inventory store; backs Tupã Inventory.
- **Tupã IDE** — native macOS IDE for intelligent software development (Rust, Slint, Metal).

## Research
